## 1. 프로젝트 주제
### 제목: 한국 DUR 노인주의 목록과 Beers Criteria 비교

한국의 Drug Utilization Review (DUR) 노인주의 기준에 포함된 유효성분과 2023 American Geriatrics Society (AGS) Beers Criteria에 포함된 의약품을 비교하는 것이 목적이다. 크게 다음의 3가지를 목적으로 한다. 첫째, 두 목록 간의 일치 정도, 둘째, 개별 성분 또는 권고사항이 서로 다른 이유, 셋째, 한국에서 유통되는 Beers-only 성분의 국내 사용량이다.

## 2. 프로젝트 배경 및 목적

1. DUR(Drug Utilization Review) 시스템이란 
    한국의 DUR 시스템은 약국에서 처방과 조제를 할 때 의약품의 안전성과 관련된 정보를 전산으로 확인할 수 있도록 하는 시스템이다. DUR 기준에는 병용금기, 연령금기, 임부금기, 용량주의, 효능군 중복, 노인주의 의약품 등이 포함된다. 
    이 중 노인주의 의약품 목록은 만 65세 이상 환자에게 처방할 때 특히 주의가 필요한 성분을 제시한 기준이다.

2. AGS Beers Criteria란
    AGS Beers Criteria는 노인에게 잠재적으로 부적절할 수 있는 의약품을 확인하기 위해 널리 사용되는 기준이다. 가장 최근 개정판은 2023년 버전이다.
    이 기준에는 특정 질환이나 증후군과 관계없이 노인에게 사용을 피하거나 주의해야 하는 의약품이 제시되어 있다. 따라서 한국 DUR의 노인주의 의약품 목록과 직접 비교하기에 적절하다.
    다만 Beers Criteria는 미국에서 개발된 기준이다. 미국의 임상환경과 의약품 시장이 반영되어 있기 때문에 한국 DUR 목록과 차이가 있다고 해서 이를 바로 오류나 누락으로 해석하기는 어렵다.

3. 노인 주의 성분 연구의 중요성 
    한국은 고령인구가 계속 증가하고 있어 노인 환자의 안전한 약물 사용이 중요해지고 있다. 노인은 여러 만성질환을 함께 가지고 있는 경우가 많고, 그만큼 여러 약물을 동시에 복용하는 경우도 많다. 또 연령에 따른 생리적 변화로 약물 이상반응이나 약물 간 상호작용에 더 취약할 수 있다. 이 때문에 노인에게 잠재적으로 부적절할 수 있는 약물을 확인하고 관리하는 과정이 필요하다. 어떤 약물을 주의 대상으로 정할 것인지 기준을 마련하는 것도 중요하다.
    한국에서는 DUR 노인주의 기준을 통해 노인 환자에게 주의가 필요한 의약품 정보를 제공하고 있다. 미국에서는 AGS Beers Criteria가 노인의 잠재적 부적절 약물 사용을 평가하는 대표적인 기준으로 사용되고 있다.
    본 연구에서는 두 기준에 어떤 성분이 포함되어 있는지 확인하고, 적용 범위와 조건에 어떤 차이가 있는지 비교하고자 했다. 이를 통해 국내 노인 의약품 안전관리 기준의 현재 특성을 파악하고, 앞으로 추가로 검토할 필요가 있는 항목을 살펴보고자 했다.

4. 현재 연구의 한계 및 알고자 하는 점
    국내에서도 Beers Criteria를 이용해 노인의 잠재적 부적절 약물 사용을 분석한 연구는 여러 차례 수행되어 왔다. 다만 현재 한국 DUR 노인주의 목록과 2023 Beers Criteria를 성분, 약물군, 적용 조건 수준에서 직접 비교한 내용은 별도로 정리할 필요가 있다.
    약국 실습과 수업 과정에서 Beers Criteria에 포함된 성분과 실제 DUR 경고 범위가 항상 같지는 않다는 점을 접했다. 이 부분이 이번 프로젝트의 출발점이 되었다. 
    먼저 두 기준에 공통으로 포함된 성분과 한쪽에만 포함된 성분을 구분하고자 했다. 이후 이러한 차이가 국내 유통 여부, 같은 약물군 안에서의 포함 범위, 투여경로, 용량, 투여기간, 적응증 등 적용 조건의 차이로 설명될 수 있는지 확인하고자 했다. 또한 Beers Criteria에는 포함되어 있지만 국내 DUR 노인주의 목록에는 포함되지 않은 성분 중 실제 국내에서 확인되는 성분의 건강보험 청구 규모도 함께 살펴보고자 했다. 이를 통해 앞으로 추가 검토가 필요한 성분을 정리하는 데 참고할 수 있다.
    이번 연구는 한국 DUR과 Beers Criteria 중 어느 기준이 더 우수한지를 판단하는 것이 목적은 아니다. 두 기준의 공통점과 차이를 같은 기준으로 정리하고, 국내 노인 약물 안전성 기준을 추가로 검토할 때 어떤 성분과 차이 유형을 먼저 살펴볼 수 있는지 제시하는 screening framework를 만드는 것을 목표로 했다.

## 3. 핵심 분석 질문 3개

### Q1. 한국 DUR 노인주의 목록과 Beers 2023 목록은 어느 정도 일치하는가?
- 구체화: 유효성분과 권고 조건을 정규화한 후, 어떤 성분/Class가 두 기준에 공통으로 포함되고, 한국 DUR 목록에만 포함되며, 또는 Beers 2023에만 포함되는지 확인  
- Primary unit: 유효 성분(`normalized_ingredient`)
- Supplementary unit: ATC level-4 pharmacological class.
- Groups: intersection, DUR-only, Beers-only.
- Measures: 각 집합의 크기, 약물군별 빈도, ingredient-level Jaccard similarity, ATC level-4 Jaccard similarity
- 분석 유형: 두 기준의 성분 목록 비교 및 약물 계열별 분포 분석

### Q2. 국내에서 허가된 Beers-only 성분 중 국내 사용량이 가장 많은 것은 무엇인가?
- 구체화: Q1에서 확인된 Beers-only 성분 가운데 국내 품목허가된 상품을 기준으로 HIRA 성분코드와 연결되는 성분을 대상으로, HIRA API에서 이용 가능한 가장 최근의 완전한 12개월 동안 전국 단위 건강보험 청구건수를 합산한다. (국내 사용량을 건강보험 청구건수로 간주)
- Unit: 월별 marketed Beers-only ingredient 12개 합계
- Variables: normalized ingredient, HIRA ingredient code, ATC level-4 class, year-month, claim count, suppression flag.
- Output: 사용량이 가장 많은 10개 성분과 해당 ATC level-4 class.
- 분석 유형: 성분별 국내 사용량 비교 및 약물 계열별 분포 분석

### Q3. DUR-only와 Beers-only 사이 불일치 항목은 무엇으로 설명할 수 있는가?
- 구체화: 각 불일치 항목을 검토하여 국내 유통 여부, 같은 pharmacological class 안에서 포함하는 성분 범위의 차이, 투여경로,용량,기간,적응증,치료 시작 여부,예외조건과 같은 적용 조건의 차이, 또는 기타 문서화된 차이로 설명할 수 있는지 확인한다.
- Unit: DUR과 Beers Criteria 간 포함 여부 또는 적용 조건이 일치하지 않는 개별 성분 및 권고 항목
- Classification variables: 국내 유통여부, pharmacological-class scope 차이, 적응증 차이, 추천 강도 차이, 기타.
- Conditional fields: 해당되는 경우 route, duration, dose, indication, treatment initiation, 기타.
- 분석 유형: 불일치 항목을 원인별로 분류하고, 유형별 항목 수를 확인한 뒤 대표 사례를 비교

2. 주요 변수
   
| 변수명 | 자료 형태 | 의미 및 활용 | 확인할 사항 |
|---|---|---|---|
| `source` | 범주형 | 자료 출처를 DUR 또는 Beers로 구분 | 출처 표기의 일관성 |
| `ingredient_name_original` | 문자형 | 원자료에 표시된 성분명 | 한글·영문 표기 및 동의어 차이 |
| `normalized_ingredient` | 문자형 | 목록 비교에 사용하는 통일된 성분명 | 염 형태나 복합성분의 잘못된 통합 |
| `criterion_id` | 문자형 | 원자료의 권고사항을 구분하는 번호 | 하나의 권고에 여러 성분이 포함될 수 있음 |
| `recommendation` | 문자형 | 해당 성분에 대한 주의 또는 권고 내용 | 원문의 의미가 지나치게 단순화되지 않았는지 확인 |
| `condition_note` | 문자형 | 투여경로, 용량, 기간, 적응증 등 적용 조건 | 조건이 없는 항목과 확인하지 못한 항목 구분 |
| `in_dur` | 논리형 | DUR 목록 포함 여부 | 성분명 연결 오류 |
| `in_beers` | 논리형 | Beers Criteria 포함 여부 | 성분명 연결 오류 |
| `comparison_group` | 범주형 | 공통, DUR-only, Beers-only 구분 | 두 포함 여부 값과 일치하는지 확인 |
| `is_approved_kr` | 논리형 | 국내 품목허가 확인 여부 | 허가 여부가 실제 유통을 의미하지는 않음 |
| `hira_ingredient_code` | 문자형 | HIRA 사용량 자료 연결에 사용하는 성분코드 | 하나의 성분에 코드가 여러 개이거나 없을 수 있음 |
| `atc_code` | 문자형 | WHO ATC 분류 코드 | 성분의 용도나 투여경로에 따라 코드가 다를 수 있음 |
| `atc_class` | 문자형 | 성분이 속한 약물 계열 | 분류가 불명확한 항목 확인 |
| `year_month` | 연월형 | 사용량 자료의 기준연월 | 최근 월 자료의 완전성 |
| `claim_count` | 숫자형 | 해당 월의 건강보험 청구건수 | 비공개 또는 결측값을 0으로 처리하지 않음 |
| `discordance_reason` | 범주형 | 두 기준이 다른 주요 이유 | 여러 이유가 함께 해당될 수 있음 |
| `evidence_note` | 문자형 | 불일치 판단에 사용한 근거 또는 출처 | 연구자의 추측과 공식 자료의 설명 구분 |

## 6. 예상 분석 방법

1. 데이터 전처리
- API로 받은 자료는 `data/raw/`에, 수작업으로 만든 자료는 `data/external/`에 보존한다. 수집일, source URL, credential을 제외한 request parameter, source version, row count를 함께 기록한다.
- 변환 전 required column, data type, categorical value, date format을 확인하고, column/source별 결측과 duplicate를 점검한다.
- 성분명은 띄어쓰기, 대문자, 동의어, salt form을 문서화된 mapping table로 정규화한다. 복합 성분은 각 구성 성분을 확인할 수 있도록 별도로 정리하며, 약물 계열 비교를 위해 ATC 분류를 연결하고 사용한 분류 기준과 버전을 기록한다.
- Beers entry의 route, dose, duration, indication, treatment initiation, exception 조건은 별도 field로 유지한다.
- 모든 merge 전 key uniqueness와 예상 관계(1:1, 1:N, N:M)를 확인하고, join 전후 row count와 unmatched-key count를 비교한다. Set membership에 영향을 미치는 mapping과 모호한 1:N mapping은 수작업으로 재검토한다.
- `PROHBT_CONTENT` 결측, mapping 실패 등은 임의로 추정하거나 0으로 대체하지 않고 상태를 그대로 기록한다. Claim count의 음수, 정수가 아닌 값은 invalid로 처리하고, 극단값은 원자료와 대조한 뒤 판단한다.

2. Q1 분석
`normalized_ingredient`와 ATC level-4 수준에서 Python set operation을 이용해 `intersection`, `DUR_only`, `Beers_only`를 계산하고, 두 수준에서 각각 Jaccard similarity를 산출한다. (J(A, B) = |A intersection B| / |A union B| )
결과는 각 set의 크기와 성분 목록, ATC level-4 class 분포로 정리한다. Ingredient membership은 벤다이어그램, class 분포는 막대그래프로 요약한다.

3. Q2 분석 
Q1에서 확인된 Beers-only 성분의 국내 품목허가, 유통 상태와 HIRA ingredient code mapping을 먼저 확인한다. 분석 가능한 성분에 대해 가장 최근의 완전한 12개월 동안 월별 전국 `claim_count`를 합산하고, 관측 가능한 12개월 총계가 큰 순서로 정리한다. 상위 10개 성분과 ATC level-4 class를 표와 horizontal bar chart로 나타낸다.

4. Q3 분석
각 DUR-only 및 Beers-only 항목을 보고 다음과 같은 분류로 나눈다.
- 국내 품목허가 여부 차이
- 동일 pharmacological class 안에서 포함하는 ingredient 범위 차이
- route, dose, duration, indication, treatment initiation, exception 등의 적용 조건 차이
- 기타

분류 기준은 실제 coding 전에 decision rule로 문서화한다. 결과는 불일치 유형별 빈도표, 필요한 경우 유형 간 교차표, 전체 coded discordance table, 그리고 근거를 포함한 대표 사례로 나타낸다. (Beers criteria의 evidence quality나 recommendation 강도는 보조 정보로 제시)

5. 검증

분석 결과가 원자료와 일치하는지 확인하고, 다른 방법으로 한 번 더 검토한다.

- Q1: DUR과 Beers Criteria의 공통 성분, DUR에만 포함된 성분, Beers에만 포함된 성분의 목록과 개수를 확인하고 약물 계열별 분포 결과와 비교한다.
- Q2: HIRA에서 확인한 월별 사용량 원자료와 12개월 합산 결과를 비교하여 계산이 올바른지 확인한다.
- Q3: 불일치 항목을 어떤 기준으로 분류했는지 기록하고, 주요 사례를 원래 DUR 및 Beers Criteria 자료와 다시 비교한다.

구체적인 검증 방법은 다음과 같다.

1. DUR API에서 수집한 자료 중 일부를 식품의약품안전처의 의약품 정보와 직접 비교한다.
2. 직접 입력한 Beers Criteria Table 2의 내용을 원문 PDF와 다시 비교한다.
3. 성분명과 ATC 분류를 연결한 결과 중 분석 결과에 영향을 주는 항목과 연결이 불확실한 항목을 직접 확인한다.
4. Beers-only 성분의 국내 유통 여부 중 일부를 식품의약품안전처 의약품 정보에서 다시 확인한다.
5. 사용량이 많은 상위 성분의 HIRA 조회 결과와 분석에서 계산한 값을 비교한다.
6. 공통, 단독 성분 수와 연간 사용량 합계는 다른 집계 방법을 사용해 한 번 더 계산하여 결과가 같은지 확인한다.
7. 연결되지 않은 성분, 결측값, 비공개 처리된 값 및 분석 과정에서 제외된 자료의 수를 기록한다.

## 8. 향후 프로젝트 계획

1. 데이터 수집
DUR 노인주의 목록과 Beers Criteria 자료를 정리하고, 분석에 필요한 MFDS와 HIRA 데이터를 수집한다. 이후 같은 자료를 다시 확인할 수 있도록 각 자료의 조회일과 버전도 함께 기록한다.

2. 데이터 전처리
자료마다 다르게 표기된 성분명을 하나의 기준으로 통일한다. 중복된 값이나 결측값이 있는지도 확인한다. 약물 계열별 비교를 위해 각 성분에 ATC 분류를 연결한다.

3. Q1. DUR과 Beers Criteria 비교
두 기준에 공통으로 포함된 성분과 한쪽에만 포함된 성분을 구분한다. 이후 약물 계열별로 어떤 차이가 있는지 비교한다.

4. 국내 유통 여부 및 사용량 데이터 수집
Beers Criteria에만 포함된 성분이 국내에서 실제로 유통되는지 확인한다. 국내 유통이 확인된 성분은 HIRA 자료를 이용해 사용량 데이터를 수집한다.

5. Q2. 국내 사용량 분석
국내에서 유통되는 Beers-only 성분의 최근 12개월 사용량을 비교한다. 사용량이 많은 성분이 무엇인지 확인하고, 해당 성분이 어떤 약물 계열에 속하는지도 함께 살펴본다.

6. Q3. 두 기준의 차이 분석
DUR과 Beers Criteria에서 서로 일치하지 않는 항목을 확인한다. 이후 국내 유통 여부, 포함되는 성분의 범위, 투여경로, 용량, 투여기간 등 적용 조건의 차이를 중심으로 그 이유를 정리한다.

7. 결과 검증 및 최종 정리
주요 분석 결과를 원자료와 다시 비교해 오류가 없는지 확인한다. 이후 분석 결과와 그래프, 표를 정리하고 결과에 대한 해석과 한계를 함께 작성한다.
